# Application modules

Rekko grows as a modular monolith. Business modules are added only by the roadmap phase that owns them and may use `application`, `domain`, `repository`, `schemas`, and `server` folders when those boundaries become useful.

Planned module boundaries are `auth`, `users`, `workspaces`, `invitations`, `projects`, `work-items`, `time-tracking`, `timeline`, `insights`, `exports`, and `integrations/linear`.
